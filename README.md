# greenhough.github.io

My personal website for talking about sales enablement, projects, and Claude.
Live at [evangreenhough.com](https://evangreenhough.com).

Built with [Astro](https://astro.build) and deployed to GitHub Pages by
[a GitHub Action](.github/workflows/deploy.yml) on every push to `main`.

```bash
npm install
npm run dev
```

- **Publishing a post or a project write-up:** [`PUBLISHING.md`](PUBLISHING.md)
- **What the words on this site mean:** [`CONTEXT.md`](CONTEXT.md)
- **Why it is built this way:** [`docs/adr/`](docs/adr/)

The pre-rebuild site is kept, frozen and noindexed, at
[`/archive/v1/`](https://evangreenhough.com/archive/v1/index.html), and tagged
`v1-flat-site`.
